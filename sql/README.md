# SQL-примеры

Четыре запроса по таблицам CV Builder выполнены 23.10.2026 через SQL-подключение Supabase на тестовом стенде `jerwfvhpoanoukxiyvwq`. Все завершились без ошибок. Полные ответы записаны в комментариях в каждом SQL-файле.

| Запрос | Что проверяет | Конструкции | Фактический результат |
|---|---|---|---|
| [Список резюме](resumes.sql) | Названия и версии выбранных документов | SELECT, WHERE, ORDER BY | Два резюме: A — revision 2, B — revision 1 |
| [Резюме и его навыки](resume-skills.sql) | Связь навыка с резюме | LEFT JOIN с одной таблицей | У резюме A навык React, level 3 |
| [Количество навыков](skill-counts.sql) | Резюме, у которых есть навыки | GROUP BY, COUNT, HAVING | У каждого из двух резюме по одному навыку |
| [Навыки без повторов](unique-skills.sql) | Разные названия навыков | DISTINCT | Одно название: React |

Запросы только читают данные. Для повторения можно подставить ID своих тестовых документов, сохранив фильтры WHERE. Пустой ответ возможен, если документы отсутствуют или недоступны пользователю; HAVING исключает резюме без навыков. SQL-доступ к базе не заменяет проверку RLS с пользовательским JWT.

[Результаты сценариев приложения](../test-results/execution.md) учитываются отдельно от этих четырёх SQL-запросов.
