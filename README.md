# CV Builder — QA-портфолио

## О проекте

Я разработал CV Builder как дипломное веб-приложение для создания IT-резюме. Здесь собрал QA-кейс: документацию, результаты и доказательства проверок. Коммерческого опыта QA у меня пока нет.

[QA-стенд](https://cv-builder-qa.vercel.app/) · [Публичное резюме](https://cv-builder-qa.vercel.app/cv) · [Исходники версии 36cdd83](https://github.com/painmoney/diplome-cv-builder/tree/36cdd833b299af165338e13137b2aa7c06935170)

## Что тестировалось

Вход, выход и сессия; создание, редактирование, копирование и удаление резюме; валидация полей; пять шаблонов, мобильный предпросмотр и экспорт. Отдельно — API, сохранение данных, конфликты версий и доступ двух пользователей к документам и файлам.

## Инструменты

Приложение: React, JavaScript, Vite, Supabase/PostgreSQL, Vercel. Технический прогон выполнен управляемым Chromium-браузером, HTTP-клиентом Node.js fetch/Supabase JS и SQL-подключением. Для самостоятельного воспроизведения подготовлена коллекция Postman.
