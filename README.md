# CV Builder — QA-портфолио

## О проекте

Я разработал CV Builder как дипломный веб-проект для создания IT-резюме. Для него подготовил отдельный QA-кейс: тестовую документацию, разбор результатов технического прогона и доказательства.

[QA-стенд](https://cv-builder-qa.vercel.app/) · [Резюме](https://cv-builder-qa.vercel.app/cv) · [Исходники проверенной версии](https://github.com/painmoney/diplome-cv-builder/tree/36cdd833b299af165338e13137b2aa7c06935170)

## Тестируемая функциональность

В QA-кейс я включил вход, выход и сессию; создание, редактирование, копирование и удаление резюме; валидацию; пять шаблонов и мобильный предпросмотр; PDF/DOCX/Markdown; REST API/RPC, конфликты версий, SQL, Storage и доступ двух пользователей.

## Инструменты и технологии

Для разработки использовал React, JavaScript, Vite и Supabase/PostgreSQL, для размещения — Vercel. В портфолио собрал примеры HTTP-запросов, SQL и Postman-коллекцию для воспроизведения.

Технический прогон выполнен управляемым Chromium-браузером, HTTP-клиентом Node.js fetch/Supabase JS и SQL SELECT. Postman в исходном прогоне не использовался.
