# CV Builder — QA-портфолио

CV Builder — мой дипломный веб-проект для создания IT-резюме. Этот репозиторий содержит отдельный QA-кейс: модель, реально выполненные проверки, результаты и доказательства. Создание приложения и проверка его поведения описаны раздельно.

**[QA-стенд](https://cv-builder-qa.vercel.app/) · [Публичное резюме](https://cv-builder-qa.vercel.app/cv) · [Исходники проверенной версии](https://github.com/painmoney/diplome-cv-builder/tree/36cdd833b299af165338e13137b2aa7c06935170)**

## Результат

56 проверок в модели: 55 исходных и 1 исследовательская. Выполнена 51: **50 Passed, 1 Failed**. Ещё **5 Blocked**, 0 Not Run. Оформлен **1 воспроизводимый дефект Major / P2**: обрезание мобильного Modern preview. Подробных тест-кейсов — 13. [Итоговый отчёт](test-results/summary.md).

Проверены Auth-сессия, CRUD/rename/copy, валидация, пять шаблонов, предпросмотр и экспорт, HTTP API/RPC, версии документов, SQL integrity/cascade, Storage и права двух пользователей. Основные сценарии работают в проверенных данных; открытый мобильный дефект и недоступные интеграции ограничивают вывод о готовности всего продукта.

## Как выполнялись проверки

Действия UI выполнены **программным управлением браузером**, запросы — **Node.js fetch / Supabase JS**, SQL — **read-only SELECT через подключение staging**. Это не утверждение о ручном прогоне, лично выполненном владельцем. Новые Playwright/Cypress/Selenium suites не создавались. Существующие автотесты приложения не изменялись. Postman и Swagger UI в этом прогоне не использовались; коллекция Postman без скриптов подготовлена для воспроизведения.

Стек приложения: React, JavaScript/JSX, Vite, Supabase Auth/Storage/RPC, PostgreSQL, Vercel. Для анализа файлов использованы pypdf, python-docx и Poppler; для версий и публикации — Git/GitHub.

## Ограничения

Не проверены реальные signup/recovery-письма, успешные OAuth/GitHub import/Puter и сетевой offline-поток. DOCX проверен по структуре/тексту, без визуального Word-просмотра. Viewport 390×844 не является реальным телефоном; точная версия Chromium не зафиксирована. Это первый прогон выбранной версии, не регрессия. Пароли, токены и данные входа тестовых аккаунтов исключены.

Тестирование относится только к Supabase staging jerwfvhpoanoukxiyvwq и отдельному Vercel QA-проекту. Production и рабочие пользовательские данные не затрагивались.
