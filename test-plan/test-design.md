# Применённый тест-дизайн

| Техника | Пример CV Builder | Выполнение |
|---|---|---|
| Классы эквивалентности | Валидный пользовательский JWT / отсутствующий / невалидный | API-01, API-09, API-10 |
| Классы эквивалентности | Допустимый email / not-an-email; пустой контакт не считаем обязательным без требования | VAL-01 |
| Граничные значения | Возраст 13, 14, 100, 101 при контракте 14–100 | VAL-02–VAL-05; VAL-04 подтверждён REST и reload |
| Переходы состояний | Создан revision 1 → save revision 2 → stale save P1005; удаление и повторное чтение | API-02, API-04, API-05, DB-03 |
| Таблица решений | Пользователь A/B × собственный/чужой документ × read/save/PATCH/DELETE | SEC-01–SEC-04, обе стороны |
| Комбинации | Один набор данных × пять HTML-шаблонов; один Modern документ × три формата экспорта | TPL-01–05, EXP-01–03 |

## Решения для доступа

| Сессия | Владелец | GET | Save RPC | PATCH/DELETE |
|---|---|---|---|---|
| A | A | Документ | Новая revision при актуальной версии | Разрешено владельцу |
| A | B | [] | P1004 | [] и отсутствие изменения |
| B | A | [] | P1004 | [] и отсутствие изменения |
| Нет JWT | Любой | Не используется как доказательство изоляции A/B | 401 permission denied | Не используется как пользовательская операция |

Проверена ограниченная матрица, не exhaustive combinatorial coverage. P1005 фактически приходит с HTTP 400: нельзя подменять его ожидаемым по привычке 409.
