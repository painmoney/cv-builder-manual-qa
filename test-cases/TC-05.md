# TC-05 — Копирование и удаление копии

**Приоритет:** High. **Проверки:** DOC-03, DOC-06.

## Предусловия

Есть сохранённый документ TC-04.

## Тестовые данные

Документ с описанием и возрастом 100.

## Шаги и ожидаемые результаты

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | В меню документа выбрать «Создать копию». | Появляется отдельный документ. |
| 2 | Открыть копию; сравнить поля и GET с оригиналом. | Данные совпадают; у копии новый UUID, своя revision=1. |
| 3 | Обновить страницу копии. | Скопированные поля сохраняются. |
| 4 | В Dashboard удалить только копию, подтвердить удаление. | Копия исчезает из списка. |
| 5 | GET обоих ID от владельца. | Для копии `[]`, оригинал доступен и не изменён. |

## Постусловия

Копия удалена, оригинал сохранён.
