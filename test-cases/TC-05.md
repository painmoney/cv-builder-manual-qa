# TC-05 Копирование и удаление копии

Приоритет: High.

## Предусловия

Сохранён документ из TC-04.

## Тестовые данные

Исходный документ с about и возрастом 100. Пароли и JWT в публичный документ не включаются.

## Шаги

1. Меню документа → Создать копию.
2. Открыть копию и сравнить поля, UUID и revision через пользовательский GET.
3. Обновить страницу копии.
4. Вернуться и удалить только копию с подтверждением.
5. Прочитать оба ID через REST.

## Ожидаемый результат

Копия имеет новый UUID и свои revision; данные совпадают; после удаления копия [], оригинал остаётся.

## Постусловия

Копия удалена, оригинал сохранён.
