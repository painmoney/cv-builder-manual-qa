# TC-02 Восстановление сессии и выход

Приоритет: High.

## Предусловия

A авторизован, открыт Dashboard.

## Тестовые данные

Пользователь A. Пароли и JWT в публичный документ не включаются.

## Шаги

1. Обновить страницу.
2. Проверить Dashboard.
3. Нажать Выйти.
4. Открыть /dashboard напрямую.

## Ожидаемый результат

После reload сессия сохранена; после выхода приватный маршрут требует входа.

## Постусловия

Сессия браузера завершена.
