# TC-06 Email и границы возраста

Приоритет: High.

## Предусловия

Открыт editor собственного синтетического документа.

## Тестовые данные

not-an-email; 13, 14, 100, 101. Пароли и JWT в публичный документ не включаются.

## Шаги

1. Ввести некорректный email и сохранить.
2. Очистить email; поочерёдно ввести каждый возраст и сохранить.
3. Для допустимых дождаться Сохранено, для остальных прочитать ошибку.
4. Оставить 100, сохранить и обновить страницу.

## Ожидаемый результат

Email/13/101 отклоняются без ложного успеха; 14/100 принимаются, 100 сохраняется после reload.

Документ содержит допустимые данные.
