# TC-07 — Предпросмотр пяти шаблонов

**Приоритет:** Medium. **Проверки:** TPL-01, TPL-02, TPL-03, TPL-04, TPL-05.

## Предусловия

Есть документ с заполненными профилем, навыком, образованием, опытом и проектом. Размер окна браузера 1280×720.

## Тестовые данные

Один синтетический документ; шаблоны Минималистичный, Академический, GitHub-стиль, Классический ATS, Современный IT.

## Шаги и ожидаемые результаты

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть предпросмотр своего документа. | Показаны заполненные данные. |
| 2 | Поочерёдно выбрать каждый из пяти шаблонов. | Для каждого видны имя, описание и заполненные разделы. |
| 3 | Сравнить отображение с данными редактора и сохранить скриншоты. | Содержимое соответствует документу, данные не теряются при смене шаблона. |

## Постусловия

Данные сохранены; выбранный шаблон может измениться. Адаптивность вынесена в TC-14.
