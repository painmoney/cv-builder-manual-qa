# TC-07 Шаблоны и адаптивность

Приоритет: Medium.

## Предусловия

Есть синтетический документ с name/about/skill/education/experience/project.

## Тестовые данные

Пять template IDs; viewport desktop и 390×844. Пароли и JWT в публичный документ не включаются.

## Шаги

1. Открыть preview документа, поочерёдно выбрать пять шаблонов.
2. Сравнить заполненные поля и сохранить screenshots.
3. Проверить editor и главную на 390 px.
4. Исследовательское дополнение: открыть Modern preview на 390 px и повторить reload.

## Ожидаемый результат

Desktop-шаблоны содержат исходные данные; на мобильной ширине важный текст не обрезается.

## Постусловия

Шаблон может сохраниться как выбранный; данные принадлежат A.
