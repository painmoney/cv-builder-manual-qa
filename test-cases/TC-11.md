# TC-11 Изоляция A и B

Приоритет: Critical.

## Предусловия

Два синтетических пользователя и по документу, credentials отдельно.

## Тестовые данные

JWT A/B; UUID своих/чужих документов. Пароли и JWT в публичный документ не включаются.

## Шаги

1. В обоих направлениях выполнить GET чужого ID.
2. Вызвать чужой save RPC.
3. Выполнить чужие PATCH и DELETE.
4. Прочитать документы владельцами и сравнить title/revision/data.
5. Вставить skills в чужой документ.
6. В браузере поочерёдно войти A/B и открыть чужой editor.
7. Отправить create без JWT и GET с невалидным JWT.

## Ожидаемый результат

Чужой GET [], save P1004, PATCH/DELETE [] без последствий; skills RLS denied; UI не открывает editor; без/с неверным JWT 401.

## Постусловия

Оба документа владельцев сохранены; браузерные сессии завершены.
