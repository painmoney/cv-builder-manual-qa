# TC-10 Контроль версий save RPC

Приоритет: Critical.

## Предусловия

Создан документ revision 1.

## Тестовые данные

p_expected_revision 1, затем повтор 1, затем not-integer. Пароли и JWT в публичный документ не включаются.

## Шаги

1. Сохранить с актуальной revision 1.
2. Проверить revision 2.
3. Повторить save с прежней revision и отличающимся title.
4. Прочитать документ владельцем.
5. Передать неверный тип revision.

## Ожидаемый результат

Первый save 200/revision 2; stale 400/P1005 без перезаписи; неверный тип 400/22P02.

## Постусловия

В БД последняя успешная версия.
