# TC-10 — Сохранение и конфликт версий

**Приоритет:** Critical. **Проверки:** API-04, API-05, API-08.

## Предусловия

Есть собственный документ revision=1, HTTP-клиент авторизован владельцем.

## Тестовые данные

p_expected_revision: 1, повторно 1, затем not-integer; разные значения title.

## Шаги и ожидаемые результаты

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | POST `/rest/v1/rpc/save_resume_full` с актуальной revision=1. | HTTP 200, revision увеличена до 2. |
| 2 | GET документа. | Сохранены новые поля и revision=2. |
| 3 | Повторить запрос сохранения с revision=1 и другим title. | HTTP 400, код P1005. |
| 4 | Прочитать документ владельцем. | Успешная версия не перезаписана. |
| 5 | Передать p_expected_revision=not-integer. | HTTP 400, код 22P02; запрос отклонён. |

## Постусловия

В БД последняя успешно сохранённая версия.
