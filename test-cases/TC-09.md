# TC-09 — Создание и чтение через API

**Приоритет:** High. **Проверки:** API-01, API-02, API-03, API-11, INT-01.

## Предусловия

Пользователь A авторизован в HTTP-клиенте; импортирована API-коллекция.

## Тестовые данные

Новый UUID; тело запроса create_resume_full из коллекции; для PATCH — отдельный собственный документ.

## Шаги и ожидаемые результаты

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | POST `/rest/v1/rpc/create_resume_full` с новым ID и данными. | HTTP 200, ID созданного документа, revision=1. |
| 2 | GET `/rest/v1/resumes?id=eq.<ID>&select=*`. | HTTP 200, один документ; поля совпадают с запросом. |
| 3 | Повторить запрос создания с тем же ID, другим title/data. | HTTP 200; повтор не создаёт дубликат. |
| 4 | Сравнить GET до и после повтора. | Исходные данные и revision не перезаписаны. |
| 5 | PATCH title отдельного собственного документа и выполнить GET. | HTTP 200; владелец читает новое название. |

## Постусловия

Документы принадлежат A. Проверки ошибочных параметров вынесены в TC-15. Успешный импорт GitHub (INT-01) не проверен: серверный токен не был настроен.
