# TC-09 Контракт create и негативные HTTP-запросы

Приоритет: High.

## Предусловия

Пользовательский JWT A; новый UUID.

## Тестовые данные

Payload create из collection; not-uuid; missing p_data. Пароли и JWT в публичный документ не включаются.

## Шаги

1. POST create_resume_full.
2. GET созданного документа.
3. Повторить create с тем же UUID и другим title/data.
4. Сравнить GET до/после.
5. Отправить невалидный UUID и payload без p_data.
6. На отдельном синтетическом документе выполнить PATCH своего title.

## Ожидаемый результат

Create revision 1; повтор не перезаписывает; ошибки 4xx; свой PATCH виден владельцу.

## Постусловия

Синтетический документ остаётся.
