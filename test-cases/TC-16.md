# TC-16 — Каскадное удаление резюме

**Приоритет:** High. **Проверки:** DB-03.

## Предусловия

Только staging; отдельный временный UUID, пользователь A и read-only SQL.

## Тестовые данные

Временный документ с навыком, образованием, опытом и проектом; исторический UUID указан в cascade.sql.

## Шаги и ожидаемые результаты

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Создать временный документ через пользовательский Create RPC и прочитать связи. | Родитель и четыре дочерних раздела существуют. |
| 2 | DELETE временного документа от владельца. | Документ удалён. |
| 3 | Выполнить SELECT из cascade.sql для удалённого ID. | В resumes, skills, education, experience и manual_projects по 0 строк. |

## Постусловия

Временный документ и зависимости удалены; основные A/B документы остаются. При самостоятельном воспроизведении подставить новый временный ID.
