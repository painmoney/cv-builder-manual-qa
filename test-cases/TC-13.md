# TC-13 — Доступность публичного резюме

**Приоритет:** High. **Проверки:** PUB-01, PUB-02, PUB-03.

## Предусловия

Публикация согласована; браузер вышел из A/B.

## Тестовые данные

`/cv` и `/cv/manual-qa.pdf`.

## Шаги и ожидаемые результаты

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `/cv` напрямую без сессии и обновить. | Имя и разделы доступны; вход и редактор не требуются. |
| 2 | Открыть PDF по прямой ссылке. | HTTP 200, Content-Type application/pdf; текст читаем. |
| 3 | Установить размер окна браузера 390×844 и просмотреть `/cv`. | Текст и основные действия доступны без скрытой обрезки. |

## Постусловия

Открыта публичная страница; вход не требуется.
