# TC-13 Публичное резюме кандидата

Приоритет: High.

## Предусловия

Публикация данных согласована владельцем; браузер вышел из A/B.

## Тестовые данные

/cv и /cv/manual-qa.pdf. Пароли и JWT в публичный документ не включаются.

## Шаги

1. Открыть /cv напрямую без сессии, обновить страницу.
2. Проверить имя/разделы, отсутствие редактора и login.
3. Открыть прямой PDF, проверить HTTP/content-type и читаемость.
4. Проверить /cv при 390 px.

## Ожидаемый результат

Резюме и PDF доступны публично, данные других пользователей не запрашиваются; viewport без обрезания.

## Постусловия

Открыта публичная страница; авторизация не требуется.
