# TC-12 — Связи резюме и связанных записей

**Приоритет:** High. **Проверки:** DB-02.

## Предусловия

Подтверждён staging; разрешён SQL-доступ только для чтения. Есть два тестовых резюме A/B с заполненными навыками, образованием, опытом и проектами.

## Тестовые данные

ID документов A/B указаны в [resumes.sql](../sql/resumes.sql). Для самостоятельного повторения использовать свои тестовые документы.

## Шаги и ожидаемые результаты

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Выполнить [resumes.sql](../sql/resumes.sql) для выбранных ID. Сравнить title и revision с ответом GET своего резюме. | Названия и версии совпадают. |
| 2 | Выполнить [resume-skills.sql](../sql/resume-skills.sql). Сравнить skill_name и level с навыками в редакторе и ответе API. | Навыки относятся к нужному resume_id; названия и уровни совпадают. |
| 3 | Через GET /rest/v1/resumes прочитать свои документы с select=id,title,revision,data,skills(skill_name,level),education(institution),experience(company),manual_projects(name). Сопоставить имя из data и заполненные разделы с редактором. | У каждого документа свои связанные записи; значения совпадают с введёнными данными. |

## Постусловия

Данные не изменены. [SQL-ответы](../sql/README.md) подтверждают часть данных; результат полной сверки с интерфейсом и API не представлен. Сценарий остаётся в тестовой документации.
