# TC-12 — Согласованность документов и SQL-связей

**Приоритет:** High. **Проверки:** DB-01, DB-02.

## Предусловия

Подтверждён staging; разрешён read-only SQL-доступ к двум синтетическим документам A/B.

## Тестовые данные

UUID из resume-join.sql; заполнены четыре дочерних раздела.

## Шаги и ожидаемые результаты

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Выполнить SELECT из `sql/resume-join.sql` (без изменения UUID исторического примера). | Одна строка на каждый указанный документ; подсчитаны дочерние записи. |
| 2 | Сравнить title, revision и имя с пользовательским API и редактором. | Значения совпадают для соответствующей версии документа. |
| 3 | При необходимости открыть дополнительный `sql/catalog.sql`. | Каталог показывает avatar_shape, ограничения, RLS и invoker RPC; сопоставить со схемой проверенной версии. |

## Постусловия

Записи не изменены. Каскад и Storage вынесены в TC-16 и TC-17; исторические ID относятся к исходным данным.
