# TC-12 — Согласованность документов и SQL-связей

**Приоритет:** High. **Проверки:** DB-01, DB-02.

## Предусловия

Подтверждён staging; разрешён SQL-доступ только для чтения к двум синтетическим документам A/B.

## Тестовые данные

Для сверки исходных результатов — UUID из архивного resume-join.sql. Для самостоятельного повторения — ID своих двух тестовых резюме с заполненными навыками, образованием, опытом и проектами.

## Шаги и ожидаемые результаты

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Выполнить [исходный запрос resume-join.sql](../evidence/raw/sql/resume-join.sql); при самостоятельном повторении подставить ID своих документов. | Одна строка на каждый указанный документ; подсчитаны связанные записи. |
| 2 | Сравнить title, revision и имя с пользовательским API и редактором. | Значения совпадают для соответствующей версии документа. |
| 3 | Сопоставить [сохранённый каталог](../evidence/raw/schema-catalog.json) со схемой проверенной версии. Исходный запрос — [catalog.sql](../evidence/raw/sql/catalog.sql). | Сведения об avatar_shape, ограничениях, RLS и RPC с правами вызывающего пользователя соответствуют схеме. |

## Постусловия

Записи не изменены. Каскадное удаление и права на файлы описаны в TC-16 и TC-17.

Это исходный сценарий DB-01/DB-02. Четыре новых [SQL-примера](../sql/README.md) — материал для самостоятельного выполнения; результаты этого кейса к ним не относятся.
