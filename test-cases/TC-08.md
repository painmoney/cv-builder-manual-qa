# TC-08 — Экспорт PDF, DOCX и Markdown

**Приоритет:** High. **Проверки:** EXP-01, EXP-02, EXP-03.

## Предусловия

Открыт предпросмотр «Современный IT» синтетического документа.

## Тестовые данные

QA Portfolio Candidate; React 3; Synthetic University; Synthetic Lab; Synthetic project.

## Шаги и ожидаемые результаты

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Скачать PDF, DOCX и Markdown штатными кнопками. | Получены файлы трёх форматов. |
| 2 | Открыть PDF и сравнить видимые имя, разделы и текст. | Документ читаем, соответствует исходным данным; дополнительно доступен анализ pypdf. |
| 3 | Прочитать DOCX через python-docx и сравнить абзацы. | Структура корректна, данные присутствуют; визуальный просмотр Word этим не подтверждается. |
| 4 | Открыть Markdown как текст, сверить разделы и ссылки. | Содержит исходные данные и ссылки. |

## Постусловия

Скачанные файлы доступны для анализа.
