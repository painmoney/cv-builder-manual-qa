# TC-08 Экспорт данных в три формата

Приоритет: High.

## Предусловия

Открыт Modern preview синтетического документа.

## Тестовые данные

QA Portfolio Candidate, React 3, Synthetic University, Synthetic Lab, Synthetic project. Пароли и JWT в публичный документ не включаются.

## Шаги

1. Скачать PDF, DOCX и Markdown штатными кнопками.
2. Проверить файл PDF через pdfinfo/pypdf и визуальный PNG.
3. Разобрать DOCX python-docx, сравнить абзацы.
4. Прочитать Markdown и сравнить текст/ссылки.

## Ожидаемый результат

Файлы скачаны и содержат данные. Отдельно фиксировать визуальный просмотр PDF и отсутствие визуального просмотра Word.

## Постусловия

Синтетические экспортные доказательства; секретов нет.
