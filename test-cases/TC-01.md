# TC-01 — Вход и доступ к приватной странице

**Приоритет:** High. **Проверки:** WEB-01, AUTH-01, AUTH-02, AUTH-03, INT-02.

## Предусловия

Подтверждённый пользователь A; сессия завершена.

## Тестовые данные

Email и пароль A из закрытого набора; заведомо неверный пароль.

## Шаги и ожидаемые результаты

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть главную без входа. | Страница доступна, есть переход ко входу. |
| 2 | Открыть `/dashboard` напрямую. | Открывается `/login`. |
| 3 | Ввести email A и неверный пароль, нажать «Войти». | Понятная ошибка; приватная страница не открывается. |
| 4 | В Postman отправить POST /auth/v1/token?grant_type=password с корректными email и паролем A; повторить с B. | HTTP 200, bearer, пользователь authenticated. |

## Постусловия

AUTH-03 подтверждает вход через API; переход в Dashboard через интерфейс этим результатом не заявляется. A авторизован. Успешный OAuth — отдельный заблокированный пункт INT-02; этот сценарий его не подтверждает.
