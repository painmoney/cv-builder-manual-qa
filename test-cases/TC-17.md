# TC-17 — Права владельца файла в Storage

**Приоритет:** High. **Проверки:** STO-01.

## Предусловия

A и B авторизованы отдельно; используется staging bucket avatars.

## Тестовые данные

Одноразовая PNG; путь `<user_id_A>/<имя>.png`.

## Шаги и ожидаемые результаты

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Загрузить PNG от A в собственный префикс. | Загрузка разрешена. |
| 2 | От B попытаться загрузить файл в префикс A. | HTTP 403, запись отклонена RLS. |
| 3 | От B попытаться удалить файл A. | Не удалён ни один объект. |
| 4 | Прочитать файл по публичному URL. | HTTP 200; файл остался после попытки B. |
| 5 | Удалить файл владельцем A. | Удалён один объект. |

## Постусловия

Временная PNG удалена. Публичное чтение аватара допустимо контрактом; проверяется запрет чужой записи и удаления.
