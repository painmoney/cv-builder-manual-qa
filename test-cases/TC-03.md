# TC-03 — Подтверждение регистрации по токену

**Приоритет:** High. **Проверки:** AUTH-06, AUTH-07.

## Предусловия

Администратор staging подготовил новый неподтверждённый синтетический аккаунт и токен подтверждения регистрации через generateLink, без отправки письма.

## Тестовые данные

Подготовленные email, пароль и хеш токена (token_hash); HTTP-клиент с доступом к Supabase Auth.

## Шаги и ожидаемые результаты

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Выполнить вход по email и паролю неподтверждённого аккаунта. | Вход отклонён: `email_not_confirmed`. |
| 2 | Через Supabase Auth verifyOtp передать token_hash и type=`signup`. | Токен подтверждён. |
| 3 | Повторить вход по email и паролю. | Вход разрешён. |

## Постусловия

Аккаунт подтверждён. AUTH-07 (реальная доставка писем регистрации и восстановления) остаётся отдельной заблокированной проверкой.
