# TC-03 Подтверждение signup-токена

Приоритет: High.

## Предусловия

Только staging; подготовлен новый синтетический неподтверждённый аккаунт.

## Тестовые данные

Уникальный аккаунт из локального закрытого набора. Пароли и JWT в публичный документ не включаются.

## Шаги

1. Подготовить signup-ссылку административным generateLink без отправки письма.
2. Попытаться выполнить password login.
3. Подтвердить hashed token через verifyOtp type signup.
4. Повторить password login.

## Ожидаемый результат

До подтверждения email_not_confirmed; после verify вход разрешён. Доставка email не следует из этого кейса.

## Постусловия

Подтверждённый синтетический аккаунт.
