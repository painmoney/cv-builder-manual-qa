# TC-04 Создание и сохранение резюме

Приоритет: Critical.

## Предусловия

A авторизован.

## Тестовые данные

QA browser portfolio; QA Portfolio Browser; about Synthetic browser edit; возраст 100. Пароли и JWT в публичный документ не включаются.

## Шаги

1. Нажать Создать резюме.
2. Заполнить название, имя и about, сохранить допустимый возраст.
3. Дождаться Сохранено.
4. Обновить прямой editor URL.
5. Сравнить поля и пользовательский GET документа.
6. Вернуться в Dashboard и переименовать через меню.

## Ожидаемый результат

Новый UUID; поля сохраняются после reload, title совпадает с REST, rename обновляет карточку.

## Постусловия

Сохранён исходный синтетический документ.
