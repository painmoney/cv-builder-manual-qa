# TC-04 — Создание, сохранение и переименование резюме

**Приоритет:** Critical. **Проверки:** DOC-01, DOC-02, DOC-04, DOC-05, NET-01, INT-03.

## Предусловия

A авторизован, открыт Dashboard.

## Тестовые данные

Название QA browser portfolio; имя QA Portfolio Browser; описание Synthetic browser edit; возраст 100.

## Шаги и ожидаемые результаты

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Нажать «Создать резюме». | Создан новый документ с собственным ID, открыт редактор. |
| 2 | Заполнить поля из тестовых данных и сохранить. | Появляется «Сохранено». |
| 3 | Обновить прямой URL редактора. | Сохранённые поля восстановлены. |
| 4 | Прочитать документ через пользовательский GET из API-коллекции. | ID и поля совпадают с редактором. |
| 5 | Вернуться в Dashboard, через меню переименовать документ. | Новое название показано на карточке. |

## Постусловия

Исходный синтетический документ сохранён. Сохранение без сети и после её восстановления (NET-01), а также Puter (INT-03) описаны в чек-листе и были заблокированы.
