# TC-15 — Ошибочные параметры Create RPC

**Приоритет:** High. **Проверки:** API-06, API-07.

## Предусловия

HTTP-клиент авторизован как A; готов корректный payload Create.

## Тестовые данные

p_resume_id=not-uuid; отдельный запрос без p_data.

## Шаги и ожидаемые результаты

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | POST Create с невалидным UUID и остальными корректными полями. | HTTP 400, код 22P02. |
| 2 | POST Create с корректным новым UUID, исключив обязательный p_data. | HTTP 404, код PGRST202; RPC не выполняется. |
| 3 | Сравнить собственные документы до и после запросов. | Новые записи не созданы, существующие не изменены. |

## Постусловия

Ошибочные запросы не меняют документы. Валидация revision остаётся в TC-10.
