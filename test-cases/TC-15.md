# TC-15 — Ошибочные параметры RPC создания

**Приоритет:** High. **Проверки:** API-06, API-07.

## Предусловия

HTTP-клиент авторизован как A; подготовлено корректное тело запроса create_resume_full.

## Тестовые данные

p_resume_id=not-uuid; отдельный запрос без p_data.

## Шаги и ожидаемые результаты

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | POST create_resume_full с невалидным UUID и остальными корректными полями. | HTTP 400, код 22P02. |
| 2 | POST create_resume_full с корректным новым UUID, исключив обязательный p_data. | HTTP 404, код PGRST202; RPC не выполняется. |
| 3 | Сравнить собственные документы до и после запросов. | Новые записи не созданы, существующие не изменены. |

## Постусловия

Ошибочные запросы не меняют документы. Валидация revision остаётся в TC-10.
